集成测试控制台 Integrated Test Console

C# WPF 启动器（管理·配置·显示） + 系统 Python 引擎（测量核心） · 实时显示 · 支持暂停 · 一配多测

1 · 总体架构（分层 + 进程边界）

C# 永远不写 SCPI，所有硬件归 Python。新增测试项目只需在 engine/projects/<新项目>/ 下加一个文件夹，C# 零改动自动发现。系统 Python 通过 requirements.txt 提供 pyvisa / numpy / matplotlib / openpyxl。

3 · 运行态：实时 + 暂停时序

暂停只发生在频点间隙，不打断 INIT:IMM / *OPC? 中间态。轮间天然等待换 DUT 确认，实现“一配多测”。

sequenceDiagram autonumber participant U as 用户/C# 运行页 participant CS as C# PyRunner participant PY as Python workflow participant HW as 仪器 CS->>PY: run --project --config --binding --out PY->>HW: OUTP ON + 初始化 loop 每个频点 CS->>PY: (若暂停) {"cmd":"pause"} PY->>PY: 点间检查标志，挂起等待 CS->>PY: {"cmd":"resume"} PY->>HW: 设 FRQ / CENT / 触发 HW-->>PY: 读数 Vout / Marker Y PY->>CS: {"type":"point", freq, val, loss} CS->>U: 表格追加 + ScottPlot 实时描点 end PY->>CS: {"type":"need_confirm", phase:"dut_done"} U->>CS: 换DUT → 确认下一轮 CS->>PY: {"cmd":"confirm_next", label:"Circuit_2"} PY->>CS: {"type":"result", csv, xlsx, png} CS->>U: 叠加对比曲线 / 打开报告目录

4 · 配置复用：一配多测 + 存档

配置由 Python 的 config_schema.json 定义，C# 自动生成表单。同一配置可跑多轮 DUT，也可存文件下次直接加载。
