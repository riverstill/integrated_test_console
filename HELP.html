集成测试控制台 v0.2.0

C# WPF 启动器（项目管理 · 框图绑定 · 配置 · 运行监控）+ 系统 Python 测量引擎。 新增测试项目只需放一个 .itcpkg 包或 Python 目录，无需改界面代码。

一、首次使用

  1. 确认目录结构：Console.WPF.exe 与 engine/、HELP.html 在同一目录。
  2. 安装 Python 依赖（系统 Python）： 
    py -3 -m pip install -r engine\requirements.txt
  3. 双击 exe，顶部状态条变绿 就绪: 2 个测试项目 即正常。

二、标准测试流程（五步）

  1. 测试项目：选中一个项目；外部项目包点“安装项目包(.itcpkg)”导入。
  2. 系统框图+仪器：点“扫描仪器”，点击绿色/灰色仪器节点绑定 VISA 地址（★为自动推荐；无硬件勾选顶部 Demo）。
  3. 测试配置：按表单调参，可“存为文件”复用，下次“从文件加载”。同一配置可用于多轮测量。
  4. 运行监控：填轮标签（如 DUT_1,DUT_2）和输出目录，点“开始运行”；支持暂停/继续/确认下一步/终止；右侧实时曲线横轴为 log10(Hz)。
  5. 历史结果：打开 results/… 查看 raw.csv / *.xlsx / *.png。

三、两个内置项目

项目拓扑流程输出
电话滤波器 300Ω（示波器法）AWG→250Ω→DUT/直通→示波器CH2(300Ω并地) 先直通校准，再多轮 DUT每轮独立曲线（未校准/直通/校准后）
射频滤波器 50Ω（频谱仪法）AWG→DUT→频谱仪 多电路轮测（每轮一标签）多 sheet Excel + 对比图

四、设置

  • 主题：跟随系统（默认，读取 Windows 应用模式）/ 浅色 / 深色。
  • Python 命令：一般保持 py -3；Store 版 Python 用 python。
  • 更新源：manifest 地址（JSON：version/downloadUrl/notes），为空则不检查更新。

五、程序更新（预留机制）

在“设置”页填入 manifest 地址后点“检查更新”。发版时同步改三处版本号： Console.WPF.csproj 的 <Version>、 engine/__init__.py 的 __version__、manifest 的 version。 manifest 格式见仓库根 update_manifest.example.json。

六、故障排查

现象处理
状态条红字“找不到引擎”确认 engine 文件夹与 exe 同级
“引擎调用失败 … exit=9009”Python 命令改成 python 或点“自动检测”
“引擎通但缺依赖”执行第 1 节的 pip 安装命令
仪器扫描为空先装 NI-VISA/Keysight VISA 及仪器 USB 驱动；或勾 Demo 模式验证流程

七、给开发者：新增测试项目

复制 engine/projects/rf_50ohm/ 为新目录（或解压一个 .itcpkg 反向参考），改 project.json / diagram.json / config_schema.json / workflow.py（实现 run(...)）， 用 python -u -m engine pack --project <id> 打包分发，接收方在第 1 页“安装项目包”即可。

原始手工脚本保留在 origin_scripts/ 备查，日常测试请使用本程序。
